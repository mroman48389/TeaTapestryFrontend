## 1. Mascots

> Our mascots can be found in src/assets/teacup mascots. There are several folders 
> representing the different stages for each image.
>
>    1. background: The original images, full size and with a background. This is the 
>       source of truth for image files. Always make copies of these files and never 
>       directly change them. They are originally generated by Claude via prompting, 
>       as Claude has the most robust image generator at this time. It can take existing 
>       images and alter them without having to start from scratch, which is a major 
>       advantage when creating a suite of images that build off each other.
>    2. transparent background: These are the background images with their backgrounds removed, 
>       leaving just the mascots.
>    3. root folder: These are optimized images that are actually used. If we increase the 
>       size in the code, we need to regenerate these from the transparent background folder 
>       as described in the Reducing File Size section below.

## 2. Removing Backgrounds from Images

>    1. Launch Photopea. 
>    2. Drag image onto screen.
>    3. Select --> Color Range. Sampled Colors and Fuzziness 40 work well. The main image should 
>       be black and the background should be white. Click Ok. You should have a dashed line around 
>       both the background and the image itself.
>    4. Layer --> Raster Mask --> Add (Reveal All). 
>    5. Make sure the Background thumbnail is selected under the Layers tab on the right panel. Then 
>       go to Edit --> Fill --> Black --> Ok
>    6. File --> Export as PNG --> Save

## 3. Reducing File Size

>    1. Launch Squoosh.
>    2. Change image type to Webp.
>    3. Make sure "Lossless" is unchecked.
>    4. Resize to twice of the display size. So, if you display at 300px, resize to 600px. Maintain 
>       the aspect ratio. NOTE: If you want to make the image larger in the app itself, you should 
>       remake the webp image from the original backgroundless png. WARNING: NEVER resize the width or 
>       height to be higher than the original size, or you will lose image quality. If the original 
>       size is sufficiently small, skip this step.
>    5. Set quality to about 90 and Effort 6 (higher number = more optimized compression, but slower 
>       for Squoosh to generate image).
>    6. Download.
